# Estudio biomecánico · ficha, informe y base de datos

Herramienta web (un único `index.html`) para registrar estudios biomecánicos de ciclismo,
generar el informe en PDF y mantener una base de datos anonimizada para investigación.

- Los datos **no** están en este repositorio. Cada estudio se guarda como un `.json`
  (más sus imágenes) en una carpeta de Google Drive compartida entre los técnicos.
- Se accede iniciando sesión con Google. Solo las cuentas añadidas como usuarios de
  prueba en el proyecto de Google Cloud pueden autorizar la aplicación.
- Permiso solicitado: `drive.file` (la herramienta solo ve los archivos que ella misma crea).
